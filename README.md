# Congressional Trading: Can Outsiders Copy Congress?

[![CI](https://github.com/rxj0102/congressional-trading-alpha/actions/workflows/ci.yml/badge.svg)](https://github.com/rxj0102/congressional-trading-alpha/actions/workflows/ci.yml)

Members of Congress must disclose their stock trades within 45 days (STOCK Act, 2012). If they trade on information the market does not have, an outsider might profit by copying them as soon as a report is filed. This repository tests that on every electronically filed House periodic transaction report from 2015 to 2026, taken directly from the Clerk of the House, and repeats the tests on the Senate's filings as a separate extension.

<!-- headline:start (generated by scripts/render_readme.py, do not edit by hand) -->
**Answer, from 37,096 House stock trades disclosed between 2015 and 2026-09 by 254 members: no.** Before the filing, stocks members bought and sold did not differ clearly (-0.33%, t = -1.6), a window no outsider can trade. From the day after the report is filed, purchases minus sales earn -0.13% over 20 trading days (t = -0.8) and -0.03% over 60 (t = -0.1). A portfolio long what members bought and short what they sold, each held 20 days after the filing, has a three-factor alpha of -0.9% a year (t = -0.4). Late filings, the signal this repository was first built on, point the wrong way: after a trade filed past the 45 day limit the stock moves against the member's position, -0.66% signed over 20 days relative to on-time filings (t = -3.4), and this holds with extreme returns trimmed and errors clustered by member (t = -3.5) and without the five members who file late most (t = -3.7). Of the six tradable tests, 1 survives a multiple-testing correction (late minus on-time filings), and it does not favour copying members.

## Design

The rules below were fixed before the first run on the rebuilt data (they are also the docstring of `src/event_study.py`).

| Choice | Rule |
|---|---|
| Events | Purchases and sales of stocks in House periodic transaction reports filed electronically from 2015 (the first year the Clerk's index lists them). Assets coded [ST]; on older forms with no asset codes, any asset with a ticker whose description does not mention options. Exchanges are dropped. |
| Public date | The report's filing date in the Clerk's index, when anyone outside Congress could first see it. Entry is the close of the next trading day. |
| Abnormal return | Stock log return minus market log return (Fama-French Mkt-RF plus RF), summed over the window. |
| Before disclosure | Close on the trade date to close on the filing date. Not tradable: it measures what members earned before anyone could copy them. |
| After disclosure | 5, 20 and 60 trading days from entry, purchases minus sales, standard errors clustered by filing date. |
| Portfolio | Each day, long every stock bought and short every stock sold in the last 20 trading days after entry, equal weights; alpha against CAPM and Fama-French three factors, Newey-West 5 lags (as in Eggers and Hainmueller 2013). |
| Late filings | Trades filed more than 45 days after they happened against trades filed on time, on the 20 day abnormal return signed by the trade (purchases positive, sales negative). This was the signal the first version of this repository was built on. |
| Multiple testing | The six tradable tests are corrected together with Holm. |

## Data

- **House periodic transaction reports**: the Clerk's yearly index `{YEAR}FD.zip` and the report PDFs at `disclosures-clerk.house.gov`, parsed by `src/house_clerk.py` with `pdftotext -layout` (poppler). Electronic filings carry a text layer; paper filings (scans, about a quarter of reports) are skipped. On the newer forms the parser finds 99.6% of the rows coded [ST]. Older forms come out of pdftotext with a broken font (mixed-case tickers such as "(lYg)"), which the parser handles. The parsed table is committed as `data/house_ptr_transactions.csv`; the PDFs are not.
- **Prices**: split- and dividend-adjusted daily closes from Yahoo Finance (`scripts/fetch_prices.py`). About a quarter of tickers are not on Yahoo, mostly companies that were later delisted or renamed, so the sample leans toward survivors.
- **Factors**: Fama-French daily factors from the Ken French Data Library.
- **Senate periodic transaction reports**: efdsearch.senate.gov, parsed by `src/senate_efd.py` from the HTML tables of electronic reports (paper reports are scanned images and are skipped). The site serves reports only after its terms of use are accepted, which restrict using them for commercial or credit purposes; the script sends that acceptance only when run with `--accept-terms`. The public date is the date the report was received.

Per-event returns are frozen in `data/snapshot/events.csv.gz`, so the analysis reruns without downloading anything.

## Reproduce

```
pip install -r requirements.txt            # plus poppler-utils for pdftotext
python -m src.house_clerk 2015 2026        # about 1 hour: index and PDFs, writes data/house_ptr_transactions.csv
python scripts/fetch_prices.py             # prices for both chambers (Yahoo rate limits; reruns resume) and factors
python -m src.senate_efd 2015 2026 --accept-terms   # only if you accept the eFD terms of use
python -m src.event_study build            # per-event returns, data/snapshot/events.csv.gz
python -m src.event_study build senate     # data/snapshot/senate_events.csv.gz
python -m src.event_study analyze          # results/metrics.json
python scripts/render_readme.py            # this page
```

The first two steps download from public sources and are not needed to check the results: `analyze` and `render_readme.py --check` run from the committed snapshot.

## What changed from the first version

The first version of this repository scored disclosures on lag, committee seat and analyst coverage and ranked them into a weekly long-short book. It never ran on real data, and it had three problems that this rebuild removes:

- **Its data sources are gone.** It read the House and Senate Stock Watcher feeds, which no longer serve data. This version reads the official filings.
- **Look-ahead.** The coverage score counted today's Finviz headlines, which the market could not see at the disclosure date, and the long and short cutoffs were set from the whole history. The ranking is now point in time (`src/signal.py`, `rank_signals`), and the coverage score is not used in the study.
- **Unsourced inputs.** Committee assignments were an example file and the committee weights were judgment calls. The study above uses neither.

The original modules (`src/scraper.py`, `src/features.py`, `src/signal.py`, `src/backtest.py`) are kept for reference.

## Limitations

- The Senate results were added after the House results were known; they use the same rules and are reported as a separate family, not pooled.
- Survivorship: tickers missing from Yahoo are mostly delisted names.
- Amounts are reported in ranges; trades are equal-weighted, not sized.
- Filings are dated, not timed, so entry waits for the next trading day's close; that is conservative for a copy strategy.
- Paper filings are skipped, about a quarter of reports.
